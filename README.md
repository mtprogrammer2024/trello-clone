# کارتابل (Trello Clone)
s
پلتفرم مدیریت پروژه ها

کاربران می‌توانند فضای کاری (Workspace)، بورد (Board)، لیست (List) و کارت (Card) بسازند و کارهای خود را به‌صورت بصری سازمان‌دهی کنند.

---

## ✨ امکانات

- 🔐 احراز هویت با Laravel Sanctum
- 🗂️ مدیریت فضاهای کاری، بوردها، لیست‌ها و کارت‌ها
- 🎨 رابط کاربری با Tailwind CSS

---

## 🛠️ تکنولوژی‌ها

**بک‌اند:** Laravel 12، Laravel Sanctum، SQLite
**فرانت‌اند:** React (Vite)، React Router، Axios، Tailwind CSS v3
